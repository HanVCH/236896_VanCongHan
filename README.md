## 1. Mô tả đề tài
Dự án xây dựng ứng dụng web quản lý món ăn hoàn chỉnh gồm Frontend (React), Backend API (Node.js/Express) và Cơ sở dữ liệu đám mây (MongoDB Atlas). Ứng dụng được đóng gói bằng Docker, lưu trữ image trên Docker Hub và triển khai dịch vụ trực tuyến trên Render.

## 2. Công nghệ sử dụng
- **Frontend**: React, Axios / Fetch API, HTML/CSS
- **Backend**: Node.js, Express.js
- **Database**: MongoDB Atlas (Mongoose)
- **Quản lý mã nguồn**: Git, GitHub
- **Đóng gói & Triển khai**: Docker, Docker Hub, Render
